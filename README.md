# My Fandom Archive｜我的追星檔案

一個以 Apink 與 SNH48 為主題的靜態網站作業原型，使用 HTML、CSS、JavaScript 製作。

## 開啟方式
1. 解壓縮整個資料夾。
2. 直接用瀏覽器開啟 `index.html`。
3. 若想編輯程式碼，可用 VS Code 開啟整個資料夾。

## 頁面清單
- `index.html`：首頁
- `apink.html`：Apink 團體檔案
- `snh48.html`：SNH48 團體檔案
- `journey.html`：追星歷程時間軸
- `concerts.html`：演唱會總覽
- `taiwan.html`：偶像在台足跡
- `collection.html`：收藏頁
- `notes.html`：Threads 風格追星碎碎念（團體／標籤篩選、日期排序）
- `concert-detail.html`：演唱會詳細紀錄（第三層頁面）
- `about.html`：關於本站

## 共用檔案
- `styles.css`：全站版型與 RWD 樣式
- `script.js`：導覽選單、貼文篩選與排序、收藏搜尋

## 修改提醒
目前演唱會、地點與追星經歷中的文字是展示用範例，請換成自己的實際內容。偶像在台足跡頁面沒有假設任何團體曾到訪特定地點。圖片區是預留區，請使用自己拍攝、取得授權或可合法使用的圖片。

## 限制
此版本為前端靜態網站，沒有後端、資料庫或管理後台。網站中文字可直接在對應 HTML 檔案修改。Google Fonts 需要網路連線；若離線使用會套用系統字型。
